# ☕ Java Basics

A beginner-friendly Java repository covering fundamental Java programming concepts.

## Portfolio projects

| Project | What it demonstrates | Tests |
|---|---|---|
| [ApplyTrack](projects/applytrack-java) | Desktop and CLI application tracking, OOP, validation and CSV persistence | 20 |
| [AuthLog Analyzer](projects/authlog-analyzer-java) | Login-log analysis, HashMap, sliding windows and HTML/CSV reports | 22 |

Both projects use Java 8-compatible code with no third-party Java dependencies. Each folder has source code, sample data, build scripts, an interview walkthrough and a verification record. These are AI-assisted learning projects.

### Run from this repository

Extract the repository ZIP or clone it, then open a terminal in the project folder.

Windows PowerShell:

```powershell
cd projects\applytrack-java
.\build.bat
java -jar applytrack.jar
```

For the analyzer, open a new terminal at the repository root:

```powershell
cd projects\authlog-analyzer-java
.\build.bat
java -jar authlog-analyzer.jar
```

Open the analyzer's `output/report.html` after running. Linux/macOS users can build with `sh build.sh` inside either project folder. A JDK with `javac` is required. JARs and personal data are excluded from this repository.
